# Serveza Digital Menu

Create a premium, modern SaaS web application called "Serveza Menu".

Core Concept:

This is a QR-based digital restaurant menu system (NOT ordering system).
Customers scan a QR code and view a beautifully designed, premium digital menu.

🎯 User Roles:

1. Restaurant Owner (Admin)

Can register and login

Has access to a dashboard

Can manage menu

2. Customer (Viewer)

No login required

Opens menu via QR link

🔐 Authentication System:

Register with:

Restaurant Name

Mobile Number

Email

Password

Optional Logo Upload

Login via email/mobile + password

🧠 Admin Dashboard Features:

1. Restaurant Profile:

Update restaurant name

Upload/change logo (optional)

Upload cover/banner image (optional)

2. Category Management:

Add category

Edit category

Delete category

Each category has:

Name

Image

3. Menu Item Management:

Add item

Edit item

Delete item

Each item includes:

Name

Description (short)

Price

Image (required)

Category (required)

Veg / Non-Veg toggle

🎨 Customer Menu UI (VERY IMPORTANT - PREMIUM FEEL):

Design a mobile-first, high-end UI similar to modern food apps.

Features:

Smooth, fast loading (under 1 second)

Dark mode (default) + Light mode toggle

Sticky category tabs (horizontal scroll)

Hero section with:

Restaurant logo/name

Cover image

Menu Layout:

Category-wise sections

Each item displayed as a card:

Large image

Item name

Short description

Price

Veg/Non-veg indicator

UX:

Smooth scrolling

Subtle animations

Clean typography

Premium spacing

⚡ Technical Requirements:

Mobile-first responsive design

Use modern UI
